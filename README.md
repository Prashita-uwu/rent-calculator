# 🏠 Rent Calculator

A simple Python-based calculator designed to calculate shared living expenses such as rent, food, and electricity bills.

## 📌 About the Project

The Rent Calculator helps people sharing a hostel room, flat, or other accommodation estimate how much each person needs to pay.

It takes the following inputs:

- 🏠 Total Rent
- 🍱 Total Food Bill
- ⚡ Electricity Bill
- 🔌 Charge Per Unit
- 👥 Number of People

The program then calculates the expenses and determines the amount to be paid per person.
